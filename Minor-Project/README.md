# Power BI Minor Project – Sales Dashboard

This project presents a basic sales dashboard created using Microsoft Power BI.

## Project Overview

The dashboard presents key sales KPIs and basic sales analysis in one page.

## Key Analysis

- Total Orders
- Total Sales
- Total Customers
- Total Products
- Total Categories
- Total Profit
- Sales by Year
- Sales by Category
- Sales by Region
- Sales by Segment
- Sales by Sub-Category
- Sales by City

## Filters

- Order Date
- Category
- Region
- Segment

## Project Type

Minor Project – Basic Power BI dashboard with simple visuals and filters.
